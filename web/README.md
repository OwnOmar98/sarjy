# Sarjy — web

Nuxt 4 frontend: voice UI, latency HUD, `/api/token` for LiveKit room tokens. See the root [README](../README.md) for the whole project and [`docs/PRD.md`](../docs/PRD.md) for the plan.

## Setup

```bash
npm install
cp .env.example .env   # fill in LiveKit Cloud credentials
```

## Development

```bash
npm run dev
```

Serves on `http://localhost:3000`.

## Typecheck, build, preview

```bash
npm run typecheck
npm run build
npm run preview
```
