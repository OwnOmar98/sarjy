# Eval harness

`run.py` drives 4 synthesized fixtures (`fixtures/*.wav`, generated by
`generate_fixtures.py` via the real GeminiTTS plugin) through the actual
production `entrypoint()`/`SarjyAgent` (`agent/main.py`) in a real LiveKit
room, then reports p50/p95 per latency stage straight from `turn_traces`.

Scoped to latency only — WER and tool-call accuracy from the original
plan (docs/PRD.md §2, §7) are future work; this closes out the Latency
pillar's p50/p95 scorecard.

Run locally from `eval/`:

```
python run.py
```

Requires the same env vars as `agent/` (LiveKit, DATABASE_URL, provider
API keys) — loaded from `agent/.env` automatically outside CI.
